# Campeones

Landing page estática construida con HTML, Tailwind CSS (CDN) y JavaScript.

## Estructura

```
Pagina web campeones/
├── campeones.html      # Página principal
├── assets/
│   ├── css/
│   │   └── styles.css  # Estilos propios
│   ├── js/
│   │   └── main.js     # Menú móvil y lógica de la página
│   └── img/            # Imágenes, logos e iconos
└── README.md
```

## Cómo previsualizar

1. Abre la carpeta en VS Code.
2. Haz clic derecho sobre `campeones.html`.
3. Selecciona **Open with Live Server**.

## Notas

- Tailwind se carga por CDN, ideal para desarrollo. Para producción conviene compilarlo.
- Las imágenes deben ir en `assets/img/` con nombres en minúsculas y sin espacios.
